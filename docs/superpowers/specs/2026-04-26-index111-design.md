## 一、产品定位

**Index111** 是 IndexRusher 的复刻版本，一款面向网站所有者、SEO 从业者和内容创作者的搜索引擎索引自动化工具。

核心价值：将「手动向 Google、Bing 提交 URL 请求索引」的重复性工作转化为全自动化的日常任务。

### 成功指标
- 用户网站平均索引时间从 "数天~数周" 缩短至 "数小时~1天"
- 支持 Google (20 URL/天) + Bing (200 URL/天) 双引擎提交
- 提供每日邮件报告，可视化索引进度

### 3.2 URL 优先级算法

```typescript
// 每日配额分配逻辑
function selectUrlsForSubmission(siteId: string, quota: number) {
  return db.query(`
    SELECT * FROM urls 
    WHERE site_id = $1
    ORDER BY 
      -- 优先级 1: 从未提交过的新 URL
      CASE WHEN last_submitted_google IS NULL THEN 0 ELSE 1 END,
      -- 优先级 2: crawled_not_indexed 状态
      CASE WHEN index_status = 'crawled_not_indexed' THEN 0 ELSE 1 END,
      -- 优先级 3: 按 priority_score 降序
      priority_score DESC,
      -- 优先级 4: 最早提交的优先重试
      last_submitted_google ASC
    LIMIT $2
  `, [siteId, quota]);
}
```

## 六、核心功能实现

### 6.1 Sitemap 解析

```typescript
import { XMLParser } from 'fast-xml-parser';

export async function parseSitemap(sitemapUrl: string) {
  const response = await fetch(sitemapUrl);
  const xml = await response.text();
  const parser = new XMLParser({ ignoreAttributes: false });
  const parsed = parser.parse(xml);
  
  // 处理 sitemap index 或普通 sitemap
  const urls = parsed.urlset?.url || [];
  return Array.isArray(urls) ? urls : [urls];
}
```

### 6.2 Google Indexing API 提交

```typescript
import { google } from 'googleapis';

export async function submitToGoogle(accessToken: string, url: string) {
  const auth = new google.auth.OAuth2();
  auth.setCredentials({ access_token: accessToken });
  
  const indexing = google.indexing({ version: 'v3', auth });
  
  await indexing.urlNotifications.publish({
    requestBody: { url, type: 'URL_UPDATED' }
  });
}
```
